# Assessment Rubric (Draft)

Total: **100 marks**. Weights are a draft for the lecturer's confirmation.

| Component | Marks | Excellent (90 to 100%) | Satisfactory (50 to 89%) | Weak (0 to 49%) |
|---|---|---|---|---|
| **A. Architecture vs organization** | 5 | Six or more features correctly classified with reasons; stored-program concept explained using the group's own data bytes | Most features correct; stored-program link stated but generic | Features misclassified or no justification |
| **B. Program** | 20 | Fits in 16 bytes; correct for all four runs; clear algorithm; overflow in Run 4 correctly explained | Works for most runs; minor documentation gaps; overflow partly explained | Does not work, exceeds 16 bytes, or undocumented |
| **C. Instruction cycle** | 20 | Complete, accurate trace; correct RTL for fetch and three execute cycles; MAR/MBR values correct | Trace mostly correct; RTL has minor errors | Trace incomplete or inconsistent with the program; RTL missing or wrong |
| **D. Control unit** | 15 | Control signals for all ten opcodes; workable horizontal format; new instruction well specified with measured savings; justified control choice | Most opcodes covered; format or new instruction partly specified | Few opcodes; no format; no justification |
| **E. Memory** | 10 | Correct capacity and address width; feasible format change with its cost; bank trace and conclusion correct | Calculations correct but analysis thin | Calculations wrong or missing |
| **F. Cache** | 15 | Complete access trace; all three configurations simulated correctly with stated write assumption; AMAT correct; differences explained by locality | Simulation mostly correct; explanation general | Trace incomplete or simulation incorrect |
| **G. Input/Output** | 10 | Correct method identified and justified; realistic polling and interrupt designs; DMA argument sound | Method correct; designs partly developed | Method wrong or answers unsupported |
| **Video** | 5 | Step-by-step run clearly explained, within time | Shows the run but explanation unclear | Missing or does not show the program running |
| **Total** | **100** | | | |

## Deductions

- Report over the page limit: up to 5 marks.
- Missing contribution statement: 5 marks.
- Traces that do not match the group's assigned inputs: Task C and Task F marked as zero until resolved with the lecturer.
